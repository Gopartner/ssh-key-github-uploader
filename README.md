ssh-key-github-uploader adalah tool command-line sederhana berbasis Bash yang:

Membuat SSH key baru (jika belum ada)

Menambahkan key ke ssh-agent

Mengunggah public key langsung ke akun GitHub menggunakan GitHub Personal Access Token (PAT)

Tanpa perlu buka browser, tanpa klik-klik manual

Cocok untuk setup cepat di laptop baru, server, atau automation CI/CD.
